# Gen AI Research Knowledge Base

A structured repo for reading, summarizing, and experimenting with Generative AI papers.

## How to use
1. Copy `paper-template.md` into the right topic folder.
2. Keep `index.md` updated (or run `python3 scripts/generate_index.py`).
3. Put per-paper experiments under `code/<paper-slug>/`.
4. HySon Labs work lives in `hyson-labs/`.

## Conventions
- Filenames: `YYYY-venue-short-title.md` or `YYYY-short-title.md`
- Tags: `["LLM","RAG","Alignment","Multimodal","Eval"]`
- Status: `todo | reading | skimmed | summarized | replicated`
